## 关于本项目

本项目 fork 自 [bggRGjQaUbCoE/PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus)。针对老旧机型播放卡顿、资源占用过高等性能问题，将播放器核心由 `media_kit` / libmpv 替换为更轻量的 `fvp` / libmdk（仅选用 AVC/H.264），以降低播放时的 CPU/内存占用、提升流畅度。

## 下载

可以从 [Releases](https://github.com/qq422162318/PiliPlus-main/releases) 下载，或克隆仓库拉取代码后在本地编译。
